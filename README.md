# Active Directory Home Lab

## Project Overview
Built a virtualized Windows Server environment to practice
Active Directory administration and basic IT support tasks.

## Lab Environment
- VMware Workstation
- Windows Server 2022 
- Windows 11 Client  
- Active Directory Domain: corp.internal

## Objectives
- Configure an Active Directory domain
- Create and manage domain user accounts
- Manage security groups
- Practice password resets
- Configure and troubleshoot DNS
- Join Windows clients to a domain
- Explore Group Policy

## Tasks Completed
- Installed Windows Server 2022
- Configured server as a Domain Controller
- Created the corp.internal domain
- Created a test domain user
- Managed security groups
- Practiced password ressets
